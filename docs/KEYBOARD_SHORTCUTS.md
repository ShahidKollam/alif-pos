# Alif POS — Keyboard shortcuts

Reference for cashiers and for the in-app Help window (**F1**).

## Global

| Shortcut | Action |
|----------|--------|
| **F1** | Open Help |
| **F2** | Go to Products and open **Add product** |
| **F3** | Open **Add customer** (Billing page modal, or Customers page) |
| **F8** | Go to Billing / new bill tab |
| **F11** | Toggle full screen |
| **Ctrl+S** / **Cmd+S** | Save or update the current bill (Billing) |
| **Ctrl+T** / **Cmd+T** | New bill tab |
| **Alt+0** | Products page + Add product modal |
| **Alt+1** | Open the **last saved bill** — focuses existing tab if open, otherwise loads it in a new tab |

## Billing — customer line

| Shortcut | Action |
|----------|--------|
| Type | Search customers; dropdown opens while typing |
| **↑ / ↓** | Move through Walk-in, matching customers, and **Add this customer** |
| **Enter** | Select highlighted row (Walk-in / customer / add) |
| **Tab** | Close dropdown and move to **W / R** |
| **Esc** | Close dropdown |

## Billing — W / R and items

| Shortcut | Action |
|----------|--------|
| **W** / **R** | Set wholesale or retail (when the W/R control is focused) |
| **Tab** (from W/R) | Jump to the product name input on the next empty line |
| **↑ / ↓** | Move between product rows (when product dropdown is closed); or navigate product suggestions / verify checkboxes |
| **Enter** on product | Pick highlighted product (skips items already on the bill) |
| **Enter** on qty | Move to product name on the next row |
| **Space / Enter** on ✓ | Toggle item verified |

## Billing — bill number

| Action | Behaviour |
|--------|-----------|
| Edit **Bill no.** and press **Enter** | Search and **load** that invoice into the current tab if found |

## Notes

- Product codes are not shown on Billing; they stay internal.
- WhatsApp and Print require the bill to be **saved** first.
- After **Save**, the bill stays open so you can add lines and **Update**.
